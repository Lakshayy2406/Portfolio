# 🌐 Personal Portfolio

A personal portfolio website presenting my profile, skills, projects, and contact information.

## Features

- Personal introduction
- Skills and technologies
- Selected projects
- Contact information
- Responsive web layout

## Tech Stack

- HTML
- CSS
- JavaScript

## Run Locally

```bash
git clone https://github.com/Lakshayy2406/Portfolio.git
cd Portfolio
```

Open `index.html` in your browser, or use VS Code Live Server.
